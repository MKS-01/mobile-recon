# Automation

Automate security testing workflows with mobile-recon.

## Scripting

### Bash Scripts

```bash
#!/bin/bash
# security-audit.sh

TARGET_PACKAGE=$1

# Extract APK
mobile-recon adb app pull $TARGET_PACKAGE

# Analyze
mobile-recon apk strings ${TARGET_PACKAGE}.apk
mobile-recon apk security ${TARGET_PACKAGE}.apk
mobile-recon apk permissions ${TARGET_PACKAGE}.apk
```

### Workflow Example

```bash
#!/bin/bash
# full-recon.sh

# 1. Network discovery
mobile-recon nmap scan quick 192.168.1.0/24

# 2. Find Android devices with ADB
mobile-recon nmap mobile adb 192.168.1.0/24

# 3. List connected devices
mobile-recon adb device list

# 4. Extract and analyze target app
mobile-recon adb app pull com.target.app
mobile-recon apk info com.target.app.apk
mobile-recon apk permissions com.target.app.apk
mobile-recon apk security com.target.app.apk
```

## Batch Processing

### Scan Multiple APKs

```bash
for apk in *.apk; do
    echo "Scanning $apk..."
    mobile-recon apk strings "$apk" >> results.txt
    mobile-recon apk security "$apk" >> results.txt
done
```

### Network Discovery

```bash
# Discover all Android devices on network
mobile-recon nmap mobile adb 192.168.1.0/24
```

## Helpful Aliases

Add to your shell config for quick access:

```bash
# Mobile Recon aliases
alias mr='mobile-recon'
alias mradb='mobile-recon adb'
alias mrnmap='mobile-recon nmap'
alias mrapk='mobile-recon apk'
alias mrios='mobile-recon ios'
```
