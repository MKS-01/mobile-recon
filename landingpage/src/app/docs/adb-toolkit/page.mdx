# ADB Toolkit

Complete Android Debug Bridge toolkit for device management, application testing, and security analysis.

## Overview

The ADB Toolkit provides a comprehensive set of commands for interacting with Android devices, managing applications, and performing security testing operations.

## Device Management

### List Devices

```bash
mobile-recon adb device list
```

### Device Information

```bash
mobile-recon adb device info
```

### Screenshot & Recording

```bash
mobile-recon adb device screenshot
mobile-recon adb device screenrecord
```

## Application Management

### List Packages

```bash
mobile-recon adb app list
```

### Install & Uninstall

```bash
mobile-recon adb app install app.apk
mobile-recon adb app uninstall com.example.app
```

### Extract APKs

```bash
mobile-recon adb app pull com.example.app
```

## Security Analysis

### Package Reconnaissance

```bash
# View package details
mobile-recon adb recon packages com.target.app
```

### Log Monitoring

```bash
# All logs
mobile-recon adb recon logcat

# Filter by package
mobile-recon adb recon logcat --package com.target.app
```

## Input Simulation

### Text & Tap

```bash
mobile-recon adb input text "Hello World"
mobile-recon adb input tap 500 800
mobile-recon adb input swipe 100 500 400 500
```

### Key Events

```bash
mobile-recon adb input keyevent BACK
mobile-recon adb input keyevent HOME
mobile-recon adb input keyevent ENTER
```

## Frida Integration

```bash
# Install Frida server
mobile-recon adb frida setup

# List running processes
mobile-recon adb frida ps
```

## Examples

### Complete Reconnaissance Workflow

```bash
# 1. Connect to device
mobile-recon adb device list

# 2. Find target app
mobile-recon adb app list

# 3. Extract APK for analysis
mobile-recon adb app pull com.target.app

# 4. Analyze APK
mobile-recon apk info com.target.app.apk
mobile-recon apk permissions com.target.app.apk

# 5. Monitor runtime behavior
mobile-recon adb recon logcat
```
