# Quick Start

Get up and running with mobile-recon in minutes.

## Prerequisites

Ensure you have mobile-recon installed. See the [Installation Guide](/docs/installation) if needed.

## Your First Commands

### 1. List Available Tools

```bash
mobile-recon list
```

Output:
```
Available tools:
  - adb-toolkit      Android Debug Bridge toolkit
  - apk-analyzer     Static APK analysis
  - ios-toolkit      iOS simulator testing
  - nmap-toolkit     Network reconnaissance
```

### 2. Interactive Mode

Launch the interactive menu:

```bash
mobile-recon interactive
```

This provides a guided interface for all tools.

### 3. Quick Device Check

Check connected Android devices:

```bash
mobile-recon adb device list
# or directly
adb-toolkit device list
```

## Common Workflows

### Android App Testing

```bash
# 1. List devices
adb-toolkit device list

# 2. Find target app
adb-toolkit app list-packages --third-party

# 3. Extract APK
adb-toolkit app pull-apk com.target.app

# 4. Analyze for secrets
apk-analyzer secrets com.target.app.apk

# 5. Monitor logs
adb-toolkit log logcat --package com.target.app
```

### Network Reconnaissance

```bash
# 1. Quick network scan
nmap-toolkit scan quick 192.168.1.0/24

# 2. Find Android devices
nmap-toolkit mobile-scan android-adb 192.168.1.0/24

# 3. Deep service scan
nmap-toolkit scan ports 192.168.1.100 --ports 1-10000
```

### APK Security Audit

```bash
# Full security analysis
apk-analyzer info app.apk
apk-analyzer permissions app.apk
apk-analyzer secrets app.apk
apk-analyzer security app.apk
```

## Tips

- Use `--help` on any command for detailed options
- Most tools support JSON output with `--json` flag
- Enable verbose mode with `-v` for debugging
