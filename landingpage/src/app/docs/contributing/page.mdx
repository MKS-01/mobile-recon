# Contributing

Help improve mobile-recon by contributing code, documentation, or bug reports.

## Getting Started

### Fork & Clone

```bash
git clone https://github.com/YOUR_USERNAME/mobile-recon.git
cd mobile-recon
```

### Create Branch

```bash
git checkout -b feature/my-new-feature
```

## Adding New Tools

### Generate Tool Scaffold

```bash
./scripts/new-tool.sh my-toolkit
```

This creates:
- `tools/my-toolkit/` - Tool directory
- `tools/my-toolkit/cmd/` - Command structure
- `tools/my-toolkit/main.go` - Entry point

### Register Tool

Add to `tools.yaml`:

```yaml
tools:
  my-toolkit:
    name: "My Toolkit"
    description: "Description here"
    path: "./tools/my-toolkit"
```

### Build & Test

```bash
go build -o my-toolkit ./tools/my-toolkit
./my-toolkit --help
```

## Code Style

- Follow Go conventions
- Use `gofmt` for formatting
- Add comments for exported functions
- Include tests for new features

## Pull Requests

1. Ensure tests pass
2. Update documentation
3. Add entry to CHANGELOG
4. Submit PR with clear description

## Reporting Issues

Use GitHub Issues for:
- Bug reports
- Feature requests
- Documentation improvements

Include:
- mobile-recon version
- OS and version
- Steps to reproduce
- Expected vs actual behavior
