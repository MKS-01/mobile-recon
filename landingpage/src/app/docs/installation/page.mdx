# Installation

Get mobile-recon up and running on your system.

## Prerequisites

Before installing mobile-recon, ensure you have the following:

- **Go 1.21+** - Required for building from source
- **Git** - For cloning the repository
- **ADB** - For Android device testing (optional)
- **Nmap** - For network scanning (optional)

## Quick Install

The fastest way to get started:

```bash
git clone https://github.com/MKS-01/mobile-recon.git
cd mobile-recon
./scripts/install.sh
```

This script will:
1. Build all toolkits
2. Install binaries to your `$GOPATH/bin`
3. Set up shell completions

## Manual Installation

### Build the CLI

```bash
git clone https://github.com/MKS-01/mobile-recon.git
cd mobile-recon
go build -o mobile-recon ./cmd/mobile-recon-cli
sudo mv mobile-recon /usr/local/bin/
```

### Build Individual Tools

```bash
# ADB Toolkit
go build -o adb-toolkit ./tools/adb-toolkit

# APK Analyzer
go build -o apk-analyzer ./tools/apk-analyzer

# iOS Toolkit
go build -o ios-toolkit ./tools/ios-toolkit

# Nmap Toolkit
go build -o nmap-toolkit ./tools/nmap-toolkit
```

## Go Install

If you have Go configured:

```bash
go install github.com/MKS-01/mobile-recon/cmd/mobile-recon-cli@latest
```

## Verify Installation

```bash
mobile-recon --version
# Output: mobile-recon v1.0.0

mobile-recon list
# Lists all available tools
```

## Platform-Specific Notes

### macOS

Install dependencies via Homebrew:

```bash
brew install go adb nmap
```

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install golang android-tools-adb nmap
```

### Windows

1. Install Go from [golang.org](https://golang.org)
2. Install ADB via Android SDK Platform Tools
3. Install Nmap from [nmap.org](https://nmap.org)

## Troubleshooting

### Command not found

Ensure `$GOPATH/bin` is in your PATH:

```bash
export PATH=$PATH:$(go env GOPATH)/bin
```

Add this to your `.bashrc` or `.zshrc` for persistence.

### Permission denied

If you encounter permission errors:

```bash
chmod +x ./scripts/install.sh
```
