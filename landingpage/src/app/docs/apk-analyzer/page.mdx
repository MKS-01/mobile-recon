# APK Analyzer

Static analysis toolkit for Android applications with comprehensive security scanning.

## Overview

APK Analyzer performs deep inspection of Android APK files without needing a device or emulator. It extracts metadata, analyzes permissions, and detects potential security issues.

## Basic Commands

### APK Information

```bash
mobile-recon apk info app.apk
```

Output includes:
- Package name
- Version code and name
- Min/Target SDK
- File size and hashes

### Permission Analysis

```bash
mobile-recon apk permissions app.apk
```

Categorizes permissions by risk level:
- **Dangerous** - Runtime permissions (camera, contacts, location)
- **Signature** - System-level permissions
- **Normal** - Low-risk permissions

Filter dangerous permissions only:

```bash
mobile-recon apk permissions -d app.apk
```

## Security Analysis

### Security Check

```bash
mobile-recon apk security app.apk
```

Checks for:
- Debuggable flag enabled
- Backup allowed
- Clear text traffic allowed
- Exported components without permissions
- Weak crypto implementations

### Manifest Analysis

```bash
mobile-recon apk manifest app.apk
```

Parses and displays the AndroidManifest.xml.

## String Extraction

### Extract All Strings

```bash
mobile-recon apk strings app.apk
```

### Filter Strings

```bash
# URLs only
mobile-recon apk strings --urls app.apk
```

## File Inspection

### List APK Contents

```bash
mobile-recon apk files app.apk
```

### Show File Tree

```bash
mobile-recon apk files --tree app.apk
```

## Full Security Audit

### Complete Workflow

```bash
# 1. Pull APK from device
mobile-recon adb app pull com.target.app

# 2. Get basic info
mobile-recon apk info com.target.app.apk

# 3. Check permissions
mobile-recon apk permissions com.target.app.apk

# 4. Run security analysis
mobile-recon apk security com.target.app.apk

# 5. Extract strings for secrets
mobile-recon apk strings com.target.app.apk
```
