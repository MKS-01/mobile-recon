# Installation

Get mobile-recon up and running on your system.

## Prerequisites

Before installing mobile-recon, ensure you have the following:

- **Go 1.21+** - Required for building from source
- **Git** - For cloning the repository
- **ADB** - For Android device testing (optional)
- **Nmap** - For network scanning (optional)

## Quick Install (Recommended)

The fastest way to get started:

```bash
git clone https://github.com/MKS-01/mobile-recon.git
cd mobile-recon
./scripts/install.sh
```

This script will:
1. Build the unified CLI (all tools included)
2. Install the binary to `$GOPATH/bin`
3. Set up shell completions

## Manual Installation

### Build the CLI

```bash
git clone https://github.com/MKS-01/mobile-recon.git
cd mobile-recon/go-tools/mobile-recon-cli
go build -o mobile-recon
mv mobile-recon ~/go/bin/
```

## Verify Installation

```bash
mobile-recon --help
# Shows all available commands

mobile-recon list
# Lists all available tools
```

## Available Commands

After installation, all tools are accessed via the unified `mobile-recon` command:

```bash
mobile-recon adb   # Android Debug Bridge toolkit
mobile-recon apk   # APK static analysis toolkit
mobile-recon ios   # iOS Simulator toolkit
mobile-recon nmap  # Network reconnaissance toolkit
```

## Platform-Specific Notes

### macOS

Install dependencies via Homebrew:

```bash
brew install go android-platform-tools nmap
```

### Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install golang adb nmap
```

### Windows

1. Install Go from [golang.org](https://golang.org)
2. Install ADB via Android SDK Platform Tools
3. Install Nmap from [nmap.org](https://nmap.org)

## Troubleshooting

### Command not found

Ensure `$GOPATH/bin` is in your PATH:

```bash
export PATH=$PATH:$(go env GOPATH)/bin
```

Add this to your `.bashrc` or `.zshrc` for persistence.

### Permission denied

If you encounter permission errors:

```bash
chmod +x ./scripts/install.sh
```
