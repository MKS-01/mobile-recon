# Quick Start

Get up and running with mobile-recon in minutes.

## Prerequisites

Ensure you have mobile-recon installed. See the [Installation Guide](/docs/installation) if needed.

## Your First Commands

### 1. List Available Tools

```bash
mobile-recon list
```

Output:
```
Available Commands:
  adb         Android Debug Bridge toolkit
  apk         Android APK static analysis toolkit
  ios         iOS Simulator toolkit
  nmap        Network reconnaissance toolkit
```

### 2. Quick Device Check

Check connected Android devices:

```bash
mobile-recon adb device list
```

## Common Workflows

### Android App Testing

```bash
# 1. List devices
mobile-recon adb device list

# 2. Find target app
mobile-recon adb app list

# 3. Extract APK
mobile-recon adb app pull com.target.app

# 4. Analyze for secrets
mobile-recon apk strings com.target.app.apk

# 5. Monitor logs
mobile-recon adb recon logcat
```

### Network Reconnaissance

```bash
# 1. Quick network scan
mobile-recon nmap scan quick 192.168.1.0/24

# 2. Find Android devices
mobile-recon nmap mobile adb 192.168.1.0/24

# 3. Deep service scan
mobile-recon nmap detect service 192.168.1.100
```

### APK Security Audit

```bash
# Full security analysis
mobile-recon apk info app.apk
mobile-recon apk permissions app.apk
mobile-recon apk strings app.apk
mobile-recon apk security app.apk
```

## Tips

- Use `--help` on any command for detailed options
- All tools are unified under the `mobile-recon` command
- Enable verbose mode with `-v` for debugging
